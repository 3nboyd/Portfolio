About This Website

About the Site

This portfolio brings together my development projects, music, and contact information in a Spotify-inspired interface.

Design and Features

The site uses a shared navigation bar, project pages, music content, and a contact form. Its layout and visual style take inspiration from Spotify.

Built With

  • HTML and CSS for page structure and styling
  • JavaScript and jQuery for interactions and animations
  • Formspree for the contact form

Each page can be previewed with a local static server. The repository README includes the setup command and a page guide; the credits here list the tools and learning resources used.

Credit & Inspirations

JQuery - Made JavaScript a lot easier to work with, allowing me to add complex functionality to my website with ease.

Formspree - Used to turn my Contact page into a functional form, making it easy for users to get in touch with me.

Google Icons - Provided a wide range of icons that I used throughout my website to enhance the user experience.

Spotify - Inspired my website's design, with its clean and minimalistic approach to user interface.

W3 Schools - Taught me a lot about web development, providing valuable resources and tutorials that helped me learn and grow as a developer.

YouTube Tutorials - A wide variety of YouTube tutorials were used to learn new skills and techniques, helping me to overcome obstacles and bring my vision to life.
