# Noah Boyd's Portfolio

A personal portfolio for my development projects, music, and contact information, with a Spotify-inspired interface built in HTML, CSS, JavaScript, and jQuery.

## Preview locally

```sh
git clone https://github.com/3nboyd/Portfolio.git
cd Portfolio
python3 -m http.server 8000
```

Open [localhost:8000](http://localhost:8000). There is no build step. The site uses external resources, including jQuery, and its contact form uses Formspree.

See [About This Website](website.html) for the implementation overview and original credits.
